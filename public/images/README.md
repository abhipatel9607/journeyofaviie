# Images Directory

## Profile Picture

Add your profile picture here as `profile.jpg` or `profile.png`.

Guidelines:

- Half portrait (face + chest visible)
- Natural smile
- Blue & black check shirt
- Neutral background
- Soft natural light
- No dramatic poses
- Recommended size: 800x800px minimum
- Format: JPG or PNG

## Project Images

Add project screenshots/images in subdirectories:

- `projects/[project-slug]/`

## Writing Images

Add images for writings in subdirectories:

- `writings/[writing-slug]/`

## Naming Convention

- Use lowercase
- Use hyphens for spaces
- Be descriptive
- Examples:
  - `profile.jpg`
  - `projects/pharma-tech/dashboard-screenshot.png`
  - `writings/ujjain/shipra-river-sunset.jpg`
